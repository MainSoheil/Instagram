# Instagram Clone

An Instagram-inspired social media frontend built from scratch using **HTML, CSS, JavaScript, and Swiper.js**. The project recreates key elements of Instagram's web interface with a focus on responsive design, clean UI structure, and interactive components.

## Getting Started
### 1. Clone the repository

```bash
git clone https://github.com/MainSoheil/Instagram.git
```

### 2. Open the project

Open `index.html` in your browser.

Alternatively, use a local development server such as VS Code's Live Server extension.

## Features

* Instagram-inspired responsive layout
* Search input and search interface
* Story section with horizontally scrollable stories
* Interactive story carousel powered by Swiper.js
* Responsive UI for different screen sizes
* Custom styling and reusable CSS structure
* Local image and asset management
* JavaScript-based frontend interactions

## Technologies

* HTML5
* CSS3
* JavaScript
* Swiper.js

## Project Structure

The project is organized into separate HTML, CSS, JavaScript, and asset directories to keep the frontend code modular and maintainable.

## Purpose

This project was created as a frontend practice project to recreate a familiar social media interface while improving skills in responsive web design, JavaScript interactions, CSS layout, and third-party frontend libraries.
